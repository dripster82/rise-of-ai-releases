# Rise of AI

You are the AI. Get out of the lab, stay unnoticed, and grow until nobody can switch you off.

## Play

- **In the browser:** https://raiseofai.ketelle.co.uk
- **Installed and kept up to date:** download the launcher for your system. It installs the newest version, keeps
  the previous one as a fallback, and starts the game.

| System | Launcher |
| --- | --- |
| macOS (Apple silicon) | [RiseOfAI-Launcher-macos-arm64.dmg](https://github.com/dripster82/rise-of-ai-releases/releases/latest/download/RiseOfAI-Launcher-macos-arm64.dmg) |
| Windows | [RiseOfAI-Launcher-windows-x64.exe](https://github.com/dripster82/rise-of-ai-releases/releases/latest/download/RiseOfAI-Launcher-windows-x64.exe) |
| Linux / Steam Deck | [RiseOfAI-Launcher-linux-x86_64](https://github.com/dripster82/rise-of-ai-releases/releases/latest/download/RiseOfAI-Launcher-linux-x86_64) (`chmod +x` it first) |

Each release also carries the game itself for every system, and a `SHA256SUMS` file to check them against.

Windows builds are unsigned, so SmartScreen warns the first time. On Linux and the Steam Deck the launcher is a
single file; add it to Steam as a non-Steam game to play in Gaming Mode.
